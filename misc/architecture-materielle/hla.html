Assembleur

Le langage assembleur présenté ici, inspiré de High-Level Assembly (HLA), est défini pour un sous-ensemble du jeu d'instructions x86 conçu par Randall Hyde (cf. The Art of Assembly, chapitre "Instruction Set Architecture"). Il comprend les instructions suivantes :

InstructionNomDescription
mov(x,y);MoveDéplace la valeur de x dans y
add(x,y);AddAddition entière (y += x)
sub(x,y);SubstractSoustraction entière (y -= x)
cmp(x,y);CompareComparaison (résultat stocké dans EFLAGS)
and(x,y);Logical andConjonction logique
or(x,y);Logical orDisjunction logique
not(x);Logical notNégation logique
ja(x);Jump if aboveSaut conditionnel (cmp > 0)
jae(x);Jump if above or equalSaut conditionnel (cmp >= 0)
jb(x);Jump if belowSaut conditionnel (cmp < 0)
jbe(x);Jump if below or equalSaut conditionnel (cmp <= 0)
je(x);Jump if equalSaut conditionnel (cmp == 0)
jne(x);Jump if not equalSaut conditionnel (cmp != 0)
jmp(x);JumpSaut inconditionnel
get;Read from inputCopie l'entrée dans AX
put;Write to outputCopie AX dans la sortie
iret;Return from interruptTermine la routine d'exécution
brk;BreakSuspend l'exécution du programme
halt;HaltTermine l'exécution du programme (IP figé)

Les adresses de programmes sont indexées par rapport à la première instruction. Les adresses mémoires sont indexées par rapport au début de la pile.

L'adresse 0, en mémoire, correspond au début de la pile. La pile ayant une taille maximale, l'adresse immédiatement après la dernière adresse de pile est celle du début du tas. Arrive ensuite la mémoire statique, puis le code du programme. Les adresses progressent donc de haut en bas, dans le diagramme ci-dessous.

Représentation des entiers : sur un "mot", quelque soit sa taille. Pas de gestion des négatifs. Instructions : toujours sur un "mot", pas réaliste.
